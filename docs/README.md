## 🚀 Sobre o projeto

Este projeto consiste no desenvolvimento de um **compilador básico capaz de traduzir código JavaScript para Go (Golang)**.

A linguagem de origem utiliza como referência o padrão **ECMAScript mantido pelo TC39**, enquanto a linguagem de destino utilizada pelo projeto é **Go**.

O projeto é desenvolvido continuamente ao longo do semestre para a disciplina de **Compiladores**.

> 🚧 **Projeto em desenvolvimento:** a implementação e a documentação evoluem ao longo do semestre.
